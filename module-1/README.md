# 📘 Module 1 – Introduction

## Overview
Module 1 sets the foundation for the training by presenting **secure software updates** as a core obligation under the **Cyber Resilience Act (CRA)**.

The module explains the regulatory requirements that **Products with Digital Elements (PDEs)** must meet regarding **update security, integrity, authenticity, and lifecycle resilience**. It also introduces a **reference software update architecture** and discusses the **main threats faced by software update systems**, highlighting why update mechanisms require strong security guarantees.

Understanding these concepts is essential before exploring the mechanisms used to secure update infrastructures.

## 📚 Learning Objectives

After completing this module, you will be able to:

- Understand the **role of software updates in the Cyber Resilience Act**
- Identify the **main regulatory requirements** related to secure updates
- Describe a **reference architecture for software update systems**
- Recognize the **main threats affecting software update infrastructures**
